# Description

This backup is intended to capture the final outputs of all simulations for my poolseq-kmers project.

The github repo is here: https://github.com/milesroberts-123/poolseq-kmers

# Contents

benchmarks.tar.gz - the snakemake benchmark output files for the simulation jobs

config.yaml - workflow parameters

exact_kmc_histo_results.tar.gz - kmer histograms of ancestral genomes used for simulations

freebayes_vg_results.tar.gz - output of freebayes after vg giraffe

freqk_ref_dedup.tar.gz - indices created by freqk

freqk_results.tar.gz - k-mer counts and allele frequencies output from freqk

kmc_histo_results_2025-12-12.tar.gz  - kmer histograms for all reference genomes on NCBI

parameters.tsv - table of simulation parameters

poolsnp_results.tar.gz - output of poolsnp after vg giraffe

slim_results.tar.gz - ground truth allele frequencies output from slim

varscan_results.tar.gz - output of varscan after vg giraffe
